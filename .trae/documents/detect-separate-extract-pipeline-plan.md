## 三、具体变更计划

### Step 6: 更新 `架构设计.md`

按下列6处修改，逐处更新：

#### 6.1 更新 §3 核心数据流（序列图）

**位置**：第71-107行（sequenceDiagram）

**变更**：将序列图中的`OCR引擎`和`版面分析`合并/替换为：
- `文本检测(PP-OCRv6 det)`
- `版面分析(PPStructure)`  
- `手写识别(PP-OCRv6 rec)`

关键改动：
```
原: OCR引擎->>OCR引擎: PaddleOCR 识别...
改: 文本检测->>文本检测: PP-OCRv6 det 检测文本区域
原: OCR引擎-->>版面分析: 逐字+行级结果
改: 文本检测-->>版面分析: 检测框列表
    版面分析->>版面分析: PPStructure布局分类+手写/印刷分离
    版面分析-->>手写识别: handwriting_boxes
    手写识别->>手写识别: PP-OCRv6 rec 逐块识别+等宽切分
    手写识别-->>比对引擎: per_char_results
```

#### 6.2 更新 §5 目录结构

**位置**：第157-189行

**变更**：
- 在 `core/` 下补充新增模块描述（text_detector, handwriting_recognizer）
- 标注 `ocr_engine.py` 已废弃（保留但不再被processor引用）

#### 6.3 更新 §6.3 流水线调度

**位置**：第266-324行

**变更**：将代码示例替换为最新 `processor.py` 中三段流水线的核心逻辑（import新模块、逐页detect→analyze→recognize）

#### 6.4 重写 §6.5 版面分析

**位置**：第334-374行

**变更**：将原有"行聚类+纯Python规则"的描述替换为新的PPStructure实现：

1. **布局元素分类** — PPStructure检测 layout type（text/title/table等）
2. **手写/印刷分离** — 按bbox高度区分（h≥70px手写，h≤50px拼音）
3. **题号检测** — 从印刷体区域中正则匹配或位置推断
4. **答案分配** — 手写区域按y坐标分配到题号区间

移除旧的`_merge_rows()`、`cluster_by_row()`等描述。

#### 6.5 更新/合并 §6.6 OCR引擎

**位置**：第376-387行

**变更**：将原`ocr_engine.py`的描述替换为新的 `text_detector.py` + `handwriting_recognizer.py` 的职责说明。保留 `ocr_engine.py` 的向后兼容标记（`ocr_pdf()` 仍可用但不再推荐）。

#### 6.6 更新 §4 技术选型明细

**位置**：第139-150行

**变更**：
- 「OCR」行更新为：PP-OCRv6 Medium（det+rec分离调用）
- 「版面分析」行更新为：PPStructure（PP-Layout_v3）
- 新增「文本检测器」和「手写识别器」行

### Step 7: 测试验证

#### 7.1 环境准备

1. 安装依赖（如未安装）：
   ```bash
   pip install -r requirements.txt
   ```
2. 准备测试PDF（使用 `data/incoming/` 下的现有文件，或按文件名模板放置）

#### 7.2 验证内容

| # | 验证项 | 预期结果 | 验证方式 |
|---|--------|----------|----------|
| 1 | PPStructure布局引擎启动 | 日志输出"PPStructure 布局引擎就绪" | `run_test.py` 运行后检查日志 |
| 2 | 文本检测区域数 | 日志输出检测到的文本区域数 | 检查 processor 日志 |
| 3 | 手写区域分离数 | 日志输出手写区域数，与预期相符 | 检查 layout_analyzer 日志 |
| 4 | 单字识别结果数 | 日志输出识别的字符数 | 检查 handwriting_recognizer 日志 |
| 5 | DP比对结果 | 日志输出 correct/uncertain/wrong 统计 | 检查 grader 日志 |
| 6 | 批注PDF生成 | output/ 下生成 `*_annotated.pdf` | 检查文件系统 |
| 7 | 数据库写入 | 数据库能查到任务记录 | Web界面或 `--show` |
| 8 | 端到端无报错 | 全程无 Exception | 日志检查 |
